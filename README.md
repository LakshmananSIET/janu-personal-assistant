# Janu Personal Assistant

Janu is a personal voice assistant designed for natural two-way conversation.

## Trial goals
- Browser-based voice conversation
- Natural female assistant personality
- Speech-to-text and text-to-speech integration
- Structured task/reminder extraction
- Trial task storage in a local Excel file
- FastAPI backend

## Safety
Do not commit API keys, passwords, phone numbers, tokens, or other secrets.
